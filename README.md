# Web Design Lab · Architectural Precision v4

[Открыть лабораторию](https://arhicoach.github.io/web-design-lab/)

10 типов секций, 21 вариант, три разные Hero-композиции. Конструктор с сортировкой, сохранением, настройками акцента / геометрии / ритма / типографики / поверхности, настоящими ширинами превью и экспортом HTML/CSS.

- [Дизайн-система](DESIGN_SYSTEM.md)
- [Инструкция переноса в Flexbe](FLEXBE.md)
- [Проверки и ограничения](QA.md)
- [Сохранённые компоненты v3](https://arhicoach.github.io/web-design-lab/components.html)
- [Источники фотографий](assets/README.md)

Статический сайт, сборка не требуется. Для локального просмотра используйте любой HTTP-сервер; открытие через file:// не поддерживает загрузку CSS через fetch. Для проверки: `npm install`, `npx playwright install chromium`, `npm test`. Можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE` для установленного Chrome. Требуется Node.js 20+.

Демо не отправляет заявки. Проекты, метрики и отзывы иллюстративные. AST-IM не изменяется.
