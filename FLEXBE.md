# Перенос Architectural Precision в Flexbe

Это инструкция для будущего внедрения. Сайт AST-IM, его страницы, хедер и футер в рамках этой работы не открывались и не изменялись.

## Общий порядок

1. На отдельной тестовой странице выберите штатный блок с нужной семантикой и составом элементов. Названия блоков в каталоге могут различаться: ниже указаны типы, а не непроверенные ID шаблонов.
2. Настройте фон #F5F3ED, текст #242923, вторичный текст #61695D, основной акцент #425B42. Отключите встроенные тени и декоративные градиенты.
3. Контейнер до 1280 px. На 1440 px поля секции до 64 px, на телефоне 20 px. Вертикальные отступы 96 / 64 / 40 px для desktop / tablet / mobile. Между фото и текстом 48–64 px; минимум 32 px на узком экране.
4. Настройте отдельные размеры заголовков для мобильной версии: основной 32–52 px, карточки 22–28 px, текст 16 px с межстрочным 1.65. Для длинного русского заголовка уменьшайте размер, не ширину промежутка.
5. Примените радиус 0, 8 или 20 px согласованно к фото и кнопкам. У картинки задайте 100% ширины собственной колонки. Не растягивайте её до 115% и не используйте отрицательные отступы к заголовку.
6. Сначала штатный блок. Если его сетка не поддерживает композицию — свободная компоновка с вложенными контейнерами. Ручное абсолютное размещение допустимо только для фоновой панорамы. При использовании собственного кода — собственные классы, без переопределения внутренних генерируемых селекторов Flexbe.
7. Проверьте адаптивные версии в редакторе и по опубликованному тестовому URL. Наличие инструкции не означает, что Flexbe уже был протестирован или изменён.

## 01 / Hero

**Задача:** сформировать образ и привести к первому диалогу. Иерархия: категория → один главный заголовок → короткое описание → один CTA → фото → служебная строка.

- A «Пространство»: штатный двухколоночный первый экран, пропорции 44/56. Фото дома справа, без наложения на текст. Высота фото 320–600 px, `cover`, фокус по зданию. Колонки центрировать по вертикали. Mobile: текст, CTA, 32 px промежутка, фото высотой 320 px.
- B «Панорама»: штатный первый экран с фоновой фотографией. Минимальная высота 660 px (mobile 680 px), тёмный слой поверх изображения с плотностью около 55–91%, текст слева. Цвет текста #F5F3ED, CTA акцентный. Не размещать текст в самой светлой зоне фото. Mobile — отдельный кроп, никакого фиксированного обрезания текста по высоте.
- C «Журнал»: свободная композиция из верхнего ряда 60/40 (заголовок / описание и CTA) и нижнего широкого фото. Промежуток до фото 32 px, фото 260–500 px. Mobile верхний ряд в одну колонку, затем фото 240 px.

Для A/B фото от 1600 px по длинной стороне; для C — широкое 1800×900. Не использовать значимые детали у краёв. CTA подключить к форме, проверить открытие/закрытие и фокус.

## 02 / Преимущества

**Задача:** объяснить ценность через три конкретных принципа. Штатный блок карточек.

A: фото 4:3 → индекс → название → 2–3 строки описания. Фото от 900×675. B: убрать фото, оставить крупный индекс и разделители; сохранить порядок смыслов. Desktop 3 колонки; tablet 2; mobile 1. Gap 32 px, от фото до индекса 24 px. Не задавать всем текстам фиксированную высоту. Проверить длинные названия и отсутствие обрезания.

## 03 / Услуги

**Задача:** показать состав предложения. A: штатный список с горизонтальными линиями, в строке индекс / название / описание / стрелка. B: 3 карточки без фото.

Desktop: название 28 px, описание 16 px, поля строки 24 px. Mobile: индекс слева, название и описание в одной правой колонке, декоративную стрелку убрать. Карточки 3 → 2 → 1. Если услуга ведёт на страницу, сделать понятную ссылку с текстовым названием и фокусом; демонстрационная стрелка не заменяет ссылку.

## 04 / Этапы

**Задача:** снизить неопределённость процесса. A: 4 карточки с верхней линией и номером 01–04. B: вертикальный список, номер в отдельной колонке 100 px (mobile 60 px).

Штатный блок этапов без соединительных стрелок, если они ломают мобильную сетку. Desktop 4 колонки, tablet 2, mobile 1. Номер 44–80 px, подзаголовок 22–28 px, описание 16 px. Каждый этап — самостоятельная группа, порядок в DOM совпадает с визуальным.

## 05 / Портфолио

**Задача:** доказать подход проектами. A: свободная сетка 7/5, первый объект занимает 2 ряда, следующие два справа. B: штатная сетка из трёх равных карточек.

Вариант A: первый кадр 3:4, правые 2:1; mobile все 4:3 и все объекты видимы. B: 4:3, 3 → 2 → 1 колонки. От фото до подписи 20 px. Подписи находятся вне фотографии; название, год, тип объекта и площадь не должны конкурировать. Фото от 1400 px, mobile можно использовать отдельный кроп. В проекте подключить карточки к реальным кейсам или галерее и проверить закрытие галереи с клавиатуры.

## 06 / Цифры

**Задача:** подтверждать масштаб, не обещать неподтверждённое. Штатный блок статистики: 4 показателя, 4 → 2 → 1 колонки. A светлый; B фон #242F24, текст #F5F3ED, вторичный #C7CEBE.

Число 44–80 px; описание 16 px; верхняя линия и внутренний отступ 24 px. Не включать анимацию счётчика по умолчанию. Заменить все демонстрационные числа подтверждёнными, указать период при необходимости.

## 07 / Отзывы

**Задача:** дать человеческое подтверждение. A: одна крупная цитата до 30ch, 24–44 px, подпись ниже с отступом 32 px. B: 2 карточки, цитата 28 px; mobile одна колонка, 26 px.

Штатный блок цитаты/отзывов без автопрокрутки. Нужны согласованные текст, имя автора, роль и объект; фото автора только с разрешением. Не публиковать лабораторные отзывы как реальные. При добавлении слайдера предусмотреть кнопки, клавиатуру и reduced motion.

## 08 / FAQ

**Задача:** снять четыре типичных вопроса перед заявкой. A: штатный аккордеон. B: открытые вопросы и ответы, каждый в отдельной группе.

Вопрос 18–20 px, ответ 16 px; ширина до 880 px; поле раскрытия минимум 44 px по высоте. Все ответы доступны без наведения. Если используете HTML — `<details><summary>…</summary><p>…</p></details>`. Проверить Tab, Enter/Space, рост высоты и отсутствие перекрытия следующей секции.

## 09 / Манифест

**Задача:** объяснить метод студии. A: двухколоночный блок 50/50: текст слева и вертикальное фото справа, gap 64 px. B: редакционный текст без фото, max 840 px.

Заголовок 32–60 px (B до 80 px), два коротких абзаца 16 px с промежутком 24 px. Фото 3:4 от 1200 px; mobile 4:3, после текста, gap 32 px. Не растягивать строку на весь широкий экран.

## 10 / CTA

**Задача:** перевести интерес в конкретное действие. A: тёмная поверхность #242F24, B: светлая. Заголовок, описание, одна кнопка, нижняя служебная строка.

Штатный CTA-блок с настроенной формой или переходом. Кнопка минимум 48 px по высоте. В форме: понятные подписи, ошибки рядом с полями, состояние отправки и подтверждение успеха; реальный получатель заявки. Без фиктивного «успешно» при сетевой ошибке. Mobile служебная строка вертикально. До запуска проверить согласия и ссылки по требованиям проекта.

## Приёмка каждой секции

На 320 / 375 / 390 / 430 / 768 / 1024 / 1440 px: нет переполнения, нет обрезанного контента, фото не касается текста, контраст читаем, CTA доступен, все проекты видимы, нет перекрытий sticky-элементами. Проверить длинные заголовки, 200% масштаб, клавиатуру, отключённые анимации и медленную загрузку фото. Отдельно проверить настоящий Safari/iPhone после переноса: Chromium-эмуляция его не заменяет.
