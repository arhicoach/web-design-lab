# Quality and completeness gate

- [ ] Source inventory completed; master document obtained or clearly flagged missing; no unsupported business facts.
- [ ] Every section/approved message mapped to a rendered prototype element; omissions explained.
- [ ] Entire 10-section narrative designed cohesively, not cosmetic changes to existing Flexbe blocks.
- [ ] Hero visually strong and CTA clearly visible; correct scope and pricing; no false claims.
- [ ] Real assets used only when provenance verified; demo placeholders visibly labelled.
- [ ] Body text readable, lines not too long; headings and descriptions form clear groups; card padding adequate.
- [ ] Desktop/tablet/mobile tested at 320, 390, 768, 1024, 1440; no overflow, clipped text, layout collisions.
- [ ] Buttons and interactions tested; demo actions distinguishable from real submissions.
- [ ] Quiz spec preserved; branching bug investigated; actual Flexbe lead submission remains unmodified.
- [ ] Keyboard focus, contrast, reduced-motion and image loading checked.
- [ ] Browser screenshots reviewed and defects corrected; if unavailable mark visual QA not done.
- [ ] Existing Web Design Lab and its tests unaffected.
- [ ] User approves visual prototype before Flexbe migration; publication only with explicit approval.
